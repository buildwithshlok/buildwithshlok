## Fonts

- **Space Grotesk**, weight 600, display typography. Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk . Original variable TTF instantiated at 600 and Latin glyphs subset to WOFF2. SIL Open Font License 1.1: `licenses/SpaceGrotesk-OFL.txt`.
- **IBM Plex Mono**, Regular, mono typography. Source: https://github.com/google/fonts/tree/main/ofl/ibmplexmono . Latin subset to WOFF2. SIL Open Font License 1.1: `licenses/IBMPlexMono-OFL.txt`. The modified mono subset is internally renamed **Shlok Profile Mono** to respect the reserved font name “Plex”. The display subset is internally named **Shlok Profile Display**. Original copyright and licence records are preserved.
- Visible text is outlined from these same font files to avoid browser font substitution in SVG-as-image mode; accessible descriptions and README alt text are provided. Both font binaries are embedded as `data:font/woff2;base64` inside every SVG. No separate font requests are made.
